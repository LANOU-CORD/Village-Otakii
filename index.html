📜 Règlement Officiel

SECTION 1 : COMPORTEMENT

1.1 Respect : Tout manque de respect envers un membre ou un staff sera sanctionné. L'humain avant tout.

1.2 Langage : Merci de modérer vos propos. Les insultes graves sont proscrites.

1.3 Pseudonymes : Votre pseudo ne doit pas être offensant ou comporter des caractères invisibles.

SECTION 2 : CONTENU

2.1 Spam : Le flood (texte, emojis, mentions) est strictement interdit.

2.2 Publicité : Aucun lien d'invitation Discord n'est toléré en dehors des partenariats officiels.

2.3 Médias : Les contenus NSFW, violents ou illégaux entraînent un bannissement immédiat.

SECTION 3 : RÉCLAMATIONS

3.1 Tickets : Pour toute plainte, utilisez le système de tickets sur Discord.

3.2 Staff : Les décisions des administrateurs sont sans appel.

🌸 En rejoignant le village, vous acceptez d'être un membre exemplaire.

❓ Foire Aux Questions

Comment devenir Staff ?

Il suffit de remplir le formulaire de recrutement sur ce site. Si votre profil nous intéresse, nous vous contacterons sur Discord.

Comment faire un partenariat ?

Utilisez le bouton "Partenariat" en haut de page. Votre serveur doit avoir une activité minimale pour être accepté.

J'ai été banni, que faire ?

Les bannissements pour non-respect des règles de sécurité sont définitifs. Pour le reste, contactez un administrateur.
